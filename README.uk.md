# Audio Combiner

[English](README.md) · **Українська**

Ретранслює звук з одного аудіопристрою одразу на кілька інших, наприклад на дві Bluetooth-гарнітури, щоб дивитися кіно вдвох.

## Завантаження

Завантажте `AudioCombiner.exe` з [останнього релізу](https://github.com/Chikanut/AudioCombiner/releases/latest) і запустіть. Встановлення не потрібне.

Потрібні Windows 10/11 і [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) (якщо його немає, Windows запропонує встановити під час першого запуску).

## Налаштування для двох гарнітур

**Варіант A — з VB-Cable (найкраща синхронізація)**

1. Встановіть безкоштовний [VB-Cable](https://vb-audio.com/Cable/) і перезавантажте ПК.
2. У «Звук Windows» зробіть **CABLE Input** пристроєм за замовчуванням.
3. У програмі виберіть джерело **[Вхід] CABLE Output**.
4. Позначте обидві гарнітури і натисніть «Старт».

Обидві гарнітури отримують звук однаково, через програму.

**Варіант B — без додаткових драйверів**

Виберіть джерелом вихід, який ви не слухаєте (наприклад, `[Вихід, перехоплення] Speakers` або HDMI-монітор) і зробіть його пристроєм за замовчуванням. Програма перехопить звук з нього і розішле на гарнітури. Сам цей вихід теж гратиме, тож прикрутіть на ньому гучність фізично або вимкніть звук монітора.

Якщо джерелом вибрати одну з гарнітур, вона гратиме напряму, а друга трохи відставатиме. Відставання можна лише додати, а не прибрати, тому так робити не варто.

## Синхронізація

Bluetooth-гарнітури різних моделей мають різну власну затримку (часто 100–250 мс).

1. Увімкніть «Метроном», щоб в обох гарнітурах клацало раз на секунду.
2. Притуліть по одному навушнику від кожної гарнітури до вух.
3. Додавайте затримку тій гарнітурі, яка клацає **раніше**, доки клацання не зіллються.
4. Вимкніть метроном.

Затримку й гучність можна міняти під час перегляду, зміни застосовуються одразу.

## Що програма робить сама

* Плавно компенсує розходження годинників пристроїв, без клацань і перезапусків буфера.
* Перепідключає гарнітуру, яка відвалилась, щойно та знову з'явиться.
* Перетворює частоту й кількість каналів під кожен пристрій.
* Попереджає, якщо вибрано режим «Hands-Free» з телефонною якістю. Тоді треба вибрати «Headphones» тієї ж гарнітури.
* Працює з трею. Може запускатися разом із Windows і одразу починати ретрансляцію.
* Сама перевіряє нові релізи на GitHub і оновлюється в один клік, не перериваючи ретрансляцію надовго.

Налаштування зберігаються в `%APPDATA%\AudioCombiner\settings.json`.

## Оновлення

Програма перевіряє нові версії при запуску і далі раз на 6 годин. Коли з'являється нова версія, внизу вікна та в меню іконки в треї з'являється пункт «Оновити». Програма завантажить новий `AudioCombiner.exe`, замінить себе і перезапуститься, а ретрансляція продовжиться.

Автоматичну перевірку можна вимкнути галочкою «Автоматично перевіряти оновлення». Посилання «Перевірити оновлення» внизу вікна працює завжди.

Якщо програма лежить у папці без права запису (наприклад, `Program Files`), замінити себе вона не зможе і запропонує відкрити сторінку релізу.

## Обмеження

Деякі Bluetooth-адаптери погано тримають дві стерео-гарнітури одночасно, і тоді звук заїкається. Програмою це не виправити, допомагає інший адаптер (Bluetooth 5.x).

## Збірка з коду

Потрібен [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:DebugType=none -o publish
```

### Випуск нової версії

Створіть на GitHub реліз з тегом `vX.Y.Z`. Workflow [`release.yml`](.github/workflows/release.yml) збере `AudioCombiner.exe` з цією версією і прикріпить його до релізу, після чого встановлені копії запропонують оновлення.
